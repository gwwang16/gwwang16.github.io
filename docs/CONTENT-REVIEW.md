# 学术主页内容评审

评审对象：`feat/astro-modern-homepage` 分支的首页、论文页、两页研究概述、早期作品页、网站地图、隐私页、404 页及旧链接。

主页应让同行和招生对象迅速了解研究方向、代表论文、在研项目和学术经历。白底单栏、蓝色标题和参考文献列表符合工科学术主页的用途。

## 内容问题与修改

| 问题                                               | 修改                                                                                         |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 简介重复顶部职务、机构及下方学历和博士后经历       | 简介只说明研究所职责和硕士生指导；完整时间线集中展示                                         |
| 研究概述使用泛化介绍，并重复首页的在研项目         | 改为具体方法和应用：地形规划、泊车、车辆控制、燃料电池管理、微纳控制与恒力机构；保留相关论文 |
| 论文页解释排列方式和链接操作，作者图例重复展开姓名 | 删除操作说明；统一为一作/通讯论文范围和 `*` 标记说明                                         |
| 早期作品页解释整理过程，标题和技术标签冗余         | 每项保留任务名称、短摘要、缩略图和源码/演示链接；统一名称与排序                              |
| 著作条目缺少作者，译名和“详情”链接占用篇幅         | 补齐作者，以原书名、出版社、年份组成简洁引用                                                 |
| 网站地图混用 Earlier work / Earlier projects       | 统一栏目名称；补充页面专属搜索摘要                                                           |
| 404 页的恢复说明偏长                               | 保留明确提示和可直接使用的恢复链接                                                           |
| 隐私页包含过时的 Disqus 和广告模板                 | 按现有 GitHub Pages 与 Analytics 实现提供简短说明和官方链接                                  |
| 内容模型遗留未使用的研究图标、主题标签等字段       | 清理未使用字段、日期函数和重复功能注释                                                       |

## 保留依据

首页保留六篇代表论文，论文页列出十四篇经核对的一作或通讯论文。完整作者、DOI、正式出版年份、卷期页码和通讯标记保留；出处与核对说明留在数据和 `SOURCES.md` 中。提前在线发表状态属于必要引用信息。

四项项目保留起止年份、资助方与中文原题；英文用于阅读，中文保留正式项目名称。学术经历、课程、学生获奖、招生信息及公开联系方式具有实际用途。十九份历史正文留在源文件中，旧教程继续跳转到八项作品摘要。

## 后续内容优先级

1. **代表成果的实证材料**：每项新成果配一张清晰的系统图或结果图，简述问题、方法和有依据的关键结果，再链接论文。
2. **可复用的研究产出**：成果已有代码、数据、视频或项目页时，直接提供对应链接。
3. **代表论文的选择**：新增成果时更新首页的六篇代表作，同时覆盖智能车辆与微纳操作两个方向；完整引用集中在论文页。

成果数值、实验结论和资源链接需来自实际论文或作者材料。当前页面的研究概述介绍已有工作；下一步提升内容深度需要这些具体材料。

格式、Astro/TypeScript 检查和生产构建通过；十项内容与设计检查、十七项 Chromium 浏览器检查通过。覆盖 320/768/1440 像素布局、键盘与无 JavaScript 访问、引用及 BibTeX 下载、旧链接跳转和七页自动无障碍检查。另已核对桌面、手机与研究页截图。
