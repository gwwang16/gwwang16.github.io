# 学术主页内容评审

评审对象：`feat/astro-modern-homepage` 分支的首页、论文页、两页研究概述、早期作品页、网站地图、隐私页、404 页及旧链接。

主页应让同行和招生对象迅速了解研究方向、代表论文、在研项目和学术经历。白底单栏、蓝色标题和参考文献列表符合工科学术主页的用途。

## 保留依据

首页保留六篇代表论文，论文页列出十四篇经核对的一作或通讯论文。完整作者、DOI、正式出版年份、卷期页码和通讯标记保留；出处与核对说明留在数据和 `SOURCES.md` 中。提前在线发表状态属于必要引用信息。

四项项目保留起止年份、资助方与中文原题；英文用于阅读，中文保留正式项目名称。首页保留学术经历、课程、简短招生信息及公开联系方式。专著与论文同属出版成果，在 Publications 页分别展示。学生竞赛成绩保留原数据和学院主页入口，避免在首页展开。十九份历史正文留在源文件中，旧教程继续跳转到八项作品摘要。

## 后续内容优先级

1. **代表成果的实证材料**：每项新成果配一张清晰的系统图或结果图，简述问题、方法和有依据的关键结果，再链接论文。
2. **可复用的研究产出**：成果已有代码、数据、视频或项目页时，直接提供对应链接。
3. **代表论文的选择**：新增成果时更新首页的六篇代表作，同时覆盖智能车辆与微纳操作两个方向；完整引用集中在论文页。

成果数值、实验结论和资源链接需来自实际论文或作者材料。当前页面的研究概述介绍已有工作；下一步提升内容深度需要这些具体材料。

## 验证范围

日常发布运行格式、Astro/TypeScript、生产构建和两项轻量内容检查：论文 ID/DOI 唯一且研究关联有效，生成页面的站内链接、资源和锚点存在。删除固定文案、内容数量、历史正文哈希和全量浏览器测试，避免正常更新内容时需要同步修改测试。调整布局或新增图片时，在本地预览中检查桌面和手机显示。
