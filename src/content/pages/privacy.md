## Hosting

This website is hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

## Analytics

This website uses Google Analytics to understand visits and page usage. Its tags can use cookies to distinguish visitors and sessions. See [Google’s Privacy Policy](https://policies.google.com/privacy) and [Google Analytics cookie information](https://support.google.com/analytics/answer/11397207). Browser settings let you manage cookies.
